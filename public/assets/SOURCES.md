# Graphic assets

Downloaded November 9, 2026. Local copies keep the static recreation independent of runtime network access.

- `teams/*.svg`: Official NHL dark-background team logos, `https://assets.nhle.com/logos/nhl/svg/{TEAM}_dark.svg`. Includes all 32 team abbreviations, including `UTA`.
- `players/hughes.png`: Jack Hughes, `https://assets.nhle.com/mugs/nhl/20262027/NJD/8481559.png`.
- `players/allen.png`: Jake Allen, `https://assets.nhle.com/mugs/nhl/20262027/NJD/8474596.png`.
- `fonts/oswald.ttf`: Google Fonts Oswald variable font, `https://raw.githubusercontent.com/google/fonts/main/ofl/oswald/Oswald%5Bwght%5D.ttf`. SIL Open Font License in `fonts/oswald-OFL.txt`.
- `fonts/share-tech-mono.ttf`: Google Fonts Share Tech Mono, `https://raw.githubusercontent.com/google/fonts/main/ofl/sharetechmono/ShareTechMono-Regular.ttf`. SIL Open Font License in `fonts/share-tech-mono-OFL.txt`.
