    - **Core concepts**
    - [Agent machines](/docs/packages/agent/machines): Author an agent machine as a typed XState state machine that decides what your agent can do, while the host executes model calls.
    - [Decisions](/docs/packages/agent/decisions): Let the model choose one currently-legal machine event, validated and retried by the machine before it is taken.
    - [Acting on events](/docs/packages/agent/act): Let the model send any number of the current state's accepted events in one tool loop, each answered with what it changed.
    - [Environment and policy](/docs/packages/agent/environment-and-policy): Split an agent into a fixed environment that people author and verify, and a policy that a model can write and improve inside it.
    - [Text requests](/docs/packages/agent/text-requests): Declare typed model calls on an agent machine and invoke them from a state, parsing structured or streamed output.
    - [Tools](/docs/packages/agent/tools): Define tools, attach them to a text request, and let the host run the tool loop while the machine stays in one state.
    - [Judgments with the AI SDK](/docs/packages/agent/judgments): Ask classification, grading, relevance, and yes/no questions with the AI SDK's experimental_decide and Jev, and branch on the typed answers in a machine.
    - [Messages](/docs/packages/agent/messages)
    - [Preset machines](/docs/packages/agent/machines-presets): Factories for proven agent shapes (tool loop, sequential, router, parallel, loop, supervisor, handoff, approval batch) that return ordinary, inspectable agent machines.
